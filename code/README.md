# Programs cited by paper B as "computed"

Rust (std only) and C, exact integer or rational arithmetic (`i128`, `u128`, `i64`, `int128`), no floating point in any decision (floating point appears in `prime_window/pw/pw.rs` mode `cheb` and in printed decimals; those outputs are evidence only and are labelled as such). Build: `bash code/build.sh` (`rustc -O`, `cc -O2`, `cargo build --release --offline` for `linear_count/l2`; nothing is run). Computed statements are labelled "computed" in the status table of the paper; none of them is used by a Lean-verified or hand-proved statement.

**Status of this directory.** The 46 programs were compiled once at packaging time (0 failures; `multi_entry/src/mm2_lib.rs` is a fragment, not a program, and is not compiled; nothing was run). The command lines are partly recorded in the `run*.sh` and `drv*.sh` scripts; there is no single reproduction script, and the claim that every number of the paper is regenerated by one command is **not** made. The identification of program and paper statement is by the packager, from the program headers and the paper's status table; it was not checked by rerunning. The scripts call `tools/launch_lite.sh` through `LAUNCH_LITE`. Some scripts name binaries (`cert2`, `lcov_a`, `lcov_new`, `lcov_q`, `lrev2`) built in the author's tree from variants whose sources are not shipped; they are the record of parameters used.
